How the flow works, and what's left to build

Matrix today runs one hardcoded approval flow written in Python. The goal is a vertical Palantir: a pre-configured base flow that each client remaps and reorders as data. This is the mechanism, and an honest account of the distance remaining.

The cut worth defending

    
Stages A and B are worth doing even
    if the platform idea is shelved entirely. A is a contained improvement to a gate you already
    maintain in two files. B closes a security gap that exists in production right now, today,
    independent of any of this. Everything from C onward is a bet on the platform thesis.
    Nothing before it is.

  







  

    Part six
    
The failure this architecture invites

  


  

    
A malformed rule is an open gate, not an error

    
While building the proof-of-concept, a precondition written through the wrong code path came
    back out of Postgres as a JSON string rather than a JSON object. JsonLogic treats a
    non-object as a literal, and a non-empty literal is truthy — so the gate evaluated
    true unconditionally, and the test suite still printed a pass.

    
A malformed Python if raises. A malformed rule row just
    permits. That asymmetry is the whole risk of moving gates from code to data, and in production it
    would be a silent authorization bypass on an approval step.

  


  
The fix is cheap but has to ship with stage A, never after:
  the evaluator refuses any rule that isn't an object, the tests assert the rule's shape
  rather than only its verdict, and CI validates every stored rule before it can be published.


  
Two more worth naming

  
    
    
  • Building the registry and continuing to hardcode alongside it, paying for
    both. The forcing function is Stage F's exit test — until a new object type ships config-only, the
    registry is cost with no return.
    • 
    
  • Column mapping alone doesn't onboard a client. Their ERP says
    CLEARED where the base ontology says positive. The proof-of-concept
    declares a value map for the 1:1 cases, but anything needing computation still needs real code.
